Visual Block Studio

Visual Block Studio is a development environment that lets you build games, apps, websites, APIs, databases, multiplayer systems and more using visual blocks and real code together.

The main idea is simple: you should be able to build things without dealing with unnecessary syntax, while still having full control when you want to write code yourself.

1. Main Features

 Visual blocks and code can be mixed together
 Build 2D and 3D games
 Create websites and applications
 Database and SQL support
 Multiplayer and room systems
 API and Web Query blocks
 HTML, CSS, JavaScript, Python and other languages
 Built-in debugging and error messages
 Project collaboration
 Version control and rollback
 Asset management and compression
 Security and sandboxing
 Creator economy and project marketplace

2. Cognitive Sieve

When starting a project, VBS asks what you are building.

It then loads the tools and blocks needed for that project instead of showing everything at once.

3. Development Environment

The editor has:

 Base Blocks and Ready Blocks
 Search
 Development workspace
 Dynamic hints
 Console
 Project settings

Blocks can also be nested together to create more advanced logic.

4. Collaboration

VBS includes tools for working on projects together.

Unfinished changes can stay inside a sandbox until they are ready. Important code can also be temporarily frozen so it is not accidentally changed.

5. Security

User code is separated from the main VBS system.

Security features include:

 Data encryption
 Personal data protection
 Fraud protection
 Hacking protection

6. Performance

VBS is designed to generate clean and optimized code while keeping projects responsive and aiming for smooth 60 FPS performance.

Assets such as images, audio and video can also be compressed automatically.

7. Time Machine

VBS can save project snapshots based on time or actions.

If something breaks, developers can go back to an earlier working version.

8. Vision

VBS is meant to sit between block programming and traditional coding.

You can start visually, write real code when needed, and build serious projects without being forced into one way of development.

This is a long-term project being built and improved by a community of developers, designers, testers and contributors.
